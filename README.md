# ⌨️ Typing Game

A modern typing game designed to help improve your **typing speed, accuracy, and consistency** through interactive typing challenges.

## ✨ Features

- 🎯 Improve typing speed and accuracy
- ⏱️ Time-based typing challenges
- 📊 Track typing performance
- ⚡ Real-time feedback
- 🎮 Simple and focused gameplay
- 📱 Responsive interface
- 🧩 Clean and minimal UI

## 🚀 Getting Started

### Prerequisites

Make sure you have the required development environment installed for the project.

### Installation

Clone the repository:

```bash
git clone https://github.com/jonasermert/Typing-Game.git
cd Typing-Game
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local development URL shown in your terminal.

## 🎮 How to Play

1. Start a typing challenge.
2. Type the displayed text as quickly and accurately as possible.
3. Complete the challenge before the timer runs out.
4. Review your typing performance.
5. Try again and improve your score.
